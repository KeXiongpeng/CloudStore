# 余弦距离

## 计算公式

余弦相似度比较两个向量的夹角。对向量 A 和向量 B，先把两个向量的对应维度相乘求和，再除以两个向量长度的乘积，得到余弦值。余弦距离通常定义为 `1 - cosine_similarity`。

## 取值范围

当向量元素非负时，余弦相似度通常在 0 到 1 之间；对应余弦距离在 0 到 1 之间。一般数学空间中的余弦相似度可以是 -1 到 1，因此对应距离可以是 0 到 2。

## 为什么适合语义检索

Embedding 向量的方向常表示语义信息。两段文本如果主题接近，它们的向量方向往往更接近，即使文本长度不同。余弦距离只关注方向，不直接比较向量长度，因此适合语义相似度检索。
