# pgvector 基础

## vector 字段

pgvector 使用 `vector` 类型存储向量。例如 BAAI/bge-m3 输出 1024 维向量时，字段可以定义为 `vector(1024)`。维度必须固定，并且写入时要使用合法的向量字面量。

## 距离运算符

pgvector 的 `<=>` 运算符计算余弦距离。余弦距离越小，两个向量的方向越接近。为了更直观，可以把余弦距离转换为相似度：`1 - cosine_distance`。

## 索引

pgvector 可以使用 HNSW 图索引加速近似最近邻查询。建立索引后，查询仍然使用距离运算符，数据库会根据索引选择近似搜索路径。

索引不是万能方案。小数据量可能直接扫描也很快；数据量增加后，索引参数和查询参数才更明显地影响召回和延迟。
